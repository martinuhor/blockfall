About this build

Blockfall is a personal web engineering project: an original falling-tiles game (not a Tetris clone), shipped as a phone-first static site on Cloudflare Pages with optional edge Functions for a Lagos-day leaderboard, privacy-light analytics, and Nigeria checkout via Paystack → Printful.

Design constraints that drove the code:

  • One ranked run per Lagos calendar day; practice is separate.
  • Deterministic tile bags so a receipt can be replayed and verified.
  • No secret keys in the browser. Commerce and webhooks stay on the edge.
  • Ads and prizes are stubs or pitch-only until legal and ops are real.

Stack: vanilla ES modules, canvas renderer, Node’s built-in test runner, Ruby only at build time for the pitch deck. See GitHub and the pitch page.

This build does not pay airtime or cash.
